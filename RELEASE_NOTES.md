Первая версия iOS-клиента для сервера [musik](https://github.com/torwin-job/musik).

**Установка:** скачай `Musik-unsigned.ipa` ниже и поставь через Sideloadly со своим Apple ID — пошагово в [README](https://github.com/DiMAKES/musik-ios#установка-на-iphone).

⚠️ С бесплатным Apple ID подпись живёт 7 дней, потом приложение нужно переподписать (повторить установку). Данные и вход сохраняются.

- Радио по вкусу, миксы, любимое, открытия, библиотека с поиском
- Плеер на один экран: дизлайк · назад · пауза · дальше · лайк, переключатели «Дальше» и «Текст»
- Фоновое воспроизведение, экран блокировки с лайком и дизлайком
