# musik для iPhone

**musik iOS** — нативное приложение для iPhone и iPad, клиент для своего
музыкального сервера [**musik**](https://github.com/torwin-job/musik).

musik — self-hosted умный плеер для твоей собственной музыкальной библиотеки.
Сервер анализирует звучание треков (CLAP-эмбеддинги), учится на твоих лайках,
скипах и дослушиваниях и собирает персональное радио, ежедневные миксы, «похожее
на любимое» и подборки забытых альбомов. Всё работает у тебя дома: музыка и
история прослушиваний никуда не уходят.

Это приложение позволяет слушать сервер с телефона: в фоне, с экрана блокировки и
с той же «умной» логикой, что у веб-интерфейса. Сам сервер нужно поставить
отдельно — инструкция в [оригинальном репозитории](https://github.com/torwin-job/musik).

## Что умеет

- **Радио по вкусу**: бесконечная очередь, которая подстраивается под лайки,
  дизлайки и скипы; у каждого трека в очереди видно, почему он попал в эфир.
- **Главная**: миксы «Для тебя», «На сегодня», по дням недели, любимые
  песни/артисты/альбомы, «Похожее на любимое», «Открытия», «Давно не звучало»,
  кнопки «Радио», «Поделиться эфиром» и «Обновить миксы».
- **Библиотека**: треки, артисты, альбомы и любимое с поиском; страницы артиста и
  альбома с похожими.
- **Плеер** на один экран: обложка, перемотка и кнопки
  дизлайк · назад · пауза · дальше · лайк. Сверху переключатели «Дальше»
  (очередь) и «Текст» (текст песни с подсветкой строки).
- **Фоновое воспроизведение** и экран блокировки: пауза, следующий трек,
  перемотка, лайк и дизлайк.
- **Профиль**: насколько сервер уже знает твой вкус, топ артистов, публичные
  ссылки на эфир для друзей (VLC/браузер), выход.

## Установка на iPhone

Приложения нет в App Store: его ставят самостоятельно («sideload») со своим
бесплатным Apple ID. Mac и платный аккаунт разработчика не нужны — подойдёт
компьютер на Windows (или macOS).

### 1. Скачай приложение

Возьми файл `Musik-unsigned.ipa` со страницы
[**Releases**](https://github.com/DiMAKES/musik-ios/releases/latest).

Самая свежая сборка всегда есть и во вкладке
[Actions](https://github.com/DiMAKES/musik-ios/actions/workflows/ios.yml):
открой последний зелёный запуск и скачай артефакт **Musik-unsigned-ipa** (это zip,
внутри `.ipa`; нужен вход в GitHub).

### 2. Установи через Sideloadly (Windows)

1. Установи **iTunes** и **iCloud** с сайта Apple — именно версии с сайта, не из
   Microsoft Store. Затем установи [Sideloadly](https://sideloadly.io).
2. Подключи iPhone кабелем к компьютеру и на телефоне нажми
   «Доверять этому компьютеру».
3. Открой Sideloadly, перетащи в него `Musik-unsigned.ipa`, введи свой Apple ID и
   нажми **Start**. Пароль уходит только в Apple — так Sideloadly подписывает
   приложение твоим аккаунтом.
4. На iPhone открой *Настройки → Основные → VPN и управление устройством*, выбери
   свой Apple ID и нажми «Доверять».
5. На iOS 16 и новее включи *Настройки → Конфиденциальность и безопасность →
   Режим разработчика* (телефон перезагрузится).

Вместо Sideloadly можно использовать [AltStore](https://altstore.io) — ограничения
те же.

### 3. Первый запуск

1. Введи адрес сервера, например `http://192.168.1.10:8787`.
2. Вставь `MUSIK_API_TOKEN` из `.env` сервера (или войди по паролю).
3. Разреши доступ к локальной сети, когда iPhone спросит.

Чтобы телефон видел сервер в домашней сети, запусти сервер с
`MUSIK_PLAYER_ADDR=0.0.0.0:8787`. Для доступа вне дома удобно использовать
Tailscale или поставить сервер за HTTPS.

## ⚠️ Подпись живёт 7 дней

Приложение, подписанное бесплатным Apple ID, работает **7 дней**. После этого
iOS перестаёт его запускать, и его нужно **переподписать** — повторить шаг 2 с тем
же `.ipa` (или новым). Вход, настройки и сессия при этом сохраняются.

- Sideloadly умеет продлевать подпись автоматически, если компьютер включён и
  телефон с ним в одной Wi-Fi сети (опция *Auto-refresh*).
- С бесплатным аккаунтом одновременно можно держать не больше 3 таких приложений.
- С платным аккаунтом разработчика Apple подпись живёт год.

## Для разработчиков

Проект описан в [`project.yml`](project.yml) (XcodeGen), `.xcodeproj` не хранится
в git. Сборку делает GitHub Actions на macOS-раннере —
[`.github/workflows/ios.yml`](.github/workflows/ios.yml): любой push собирает
неподписанный `.ipa`, а сборка ветки `main` выкладывает его в Release
`v<MARKETING_VERSION>` из `project.yml` (создаёт релиз или обновляет файл в нём).
Чтобы выпустить новую версию, подними `MARKETING_VERSION`; описание релиза — в
[`RELEASE_NOTES.md`](RELEASE_NOTES.md).

Локально на Mac:

```bash
brew install xcodegen
xcodegen generate && open Musik.xcodeproj
```

Структура: `Musik/App` (точка входа, состояние приложения), `Musik/Core`
(API-клиент, модели, Keychain, обложки), `Musik/Playback` (плеер на AVPlayer,
экран блокировки), `Musik/Views` (экраны SwiftUI).

Поток запрашивается как `?q=mobile` (AAC/MP3, если сервер уже перекодировал трек,
иначе оригинал). iOS играет MP3, AAC/M4A, ALAC, FLAC и WAV; трек в
неподдерживаемом формате (например, OGG) пропускается с уведомлением.
